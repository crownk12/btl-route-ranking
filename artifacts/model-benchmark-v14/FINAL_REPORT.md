# FINAL_REPORT — 순위 모델 성능 개선 (model-benchmark-v14)

2026-10-05 · 패널 `btl-test-3-calibrated`(17품목, 종료월 2026-09) · 이전 배포 `xgb-ranker-25f-v3-calibrated-17items` → 새 배포 `xgb-v2f-v3-calibrated-17items`

> 결론: 주평가지표(양성이 있는 질의의 NDCG@5)는 시험 구간에서 **0.7210 → 0.7472**(같은 프로토콜), 검증 구간에서 **0.6996 → 0.7601**로 올랐다. **목표 0.85에는 도달하지 못했다.** 이 패널에서는 기준월의 이력으로 알 수 없는 정보(아직 오지 않은 성장 에피소드의 시작·정점 시점)가 라벨을 좌우하기 때문이며, 그 근거는 6절에 있다. 수치는 모두 관측 보정 생성 패널 안의 순위 성능이고 실제 제재 우회 적중률이 아니다.

## 1. 기존 모델과 평가 방식 진단

| 항목 | 기존 (v13) |
|---|---|
| 모델 | XGBoost Ranker `rank:ndcg` 300그루(깊이 8) + Extra Trees 64그루(미래 로그비 보조) |
| 피처 | 25개 — 최근 24개월 이력의 증가율·변동성·변화점·미러 격차 등 |
| 학습 행 | 224,467행(4개월 간격 기준월, 전망 3·6·12·24·60·75개월) |
| 라벨 | 미래 3개월 평균이 최근 3개월 평균 대비 수입 +15% **그리고** 수출 +20% 초과 |
| 질의 | 대상국 × HS6 × 기준월 × 전망기간, 후보국 8~9개 |
| 분할 | 학습(라벨 성숙 ≤ 2018-12) / 검증(기준월 2019-01~, 성숙 ≤ 2021-12) / 시험(기준월 2022-01~) |
| 기록된 성능 | NDCG@5 검증 0.4390 / 시험 0.4497, 목표 0.93 미달 |

발견한 문제:

1. **지표 정의가 목표를 불가능하게 만들었다.** 양성이 한 건도 없는 질의는 순서와 무관하게 NDCG 0으로 계산돼 평균에 들어갔다. 양성이 있는 질의는 검증 62.4%, 시험 62.5%뿐이라 완벽한 순위도 0.62를 넘지 못한다. 기존 0.4497은 이 상한의 72%였다.
2. **무작위 기준선이 높다.** 질의당 후보 8.7개 중 양성이 평균 3.6개여서 무작위 순위도 양성 있는 질의의 NDCG@5가 0.49(검증) / 0.54(시험)다. 지표의 실제 범위는 0.5~1.0이다.
3. **피처가 라벨이 묻는 것을 재지 않았다.** 라벨은 "예측 구간이 현재 구간보다 얼마나 높은가"인데, 기존 피처에는 예측 구간의 계절 위치, 경로가 오르는 중인지 내리는 중인지, 현재 3개월이 자기 추세에서 얼마나 벗어났는지가 없었다. 미래 로그비 회귀의 R²는 전망 3개월에서도 0.6~0.7, 24개월에서는 0.2~0.45였다.
4. **누수는 없었다.** 피처는 이용 가능월 ≤ 기준월만 쓰고, 분할은 라벨 성숙월 기준으로 겹치지 않는다. 기존 수치는 정확히 재현됐다(검증 0.438999, 시험 0.449727).
5. 클래스 불균형(양성률 23~32%)·모델 종류·하이퍼파라미터는 병목이 아니었다(3절).

## 2. 평가 설계

- **주평가지표**: 양성이 1건 이상인 질의의 NDCG@5(`ndcg_at_5_pos`). 사용자 결정(2026-10-04). 기존 정의(`ndcg_at_5`, 전체 질의 평균)도 계속 함께 기록한다.
- **탐색**: 학습 구간 안의 3개 롤링 폴드(절단 2009-12 / 2012-12 / 2015-12, 각 절단 뒤 36개월을 채점). 피처·모델·하이퍼파라미터는 이 평균으로 고른다.
- **확정**: 학습 → 검증. 폴드에서 동률(0.002 이내)인 후보 사이의 선택에만 쓴다.
- **최종**: 학습 → 시험. 구성을 확정한 뒤 **한 번** 읽었다. 시험 수치를 보고 고친 것은 없다.
- 검증·시험 질의는 v13과 같은 행이다(질의 ID 해시 일치). 학습 기준월만 월 단위로 늘렸다.
- Recall@10은 후보가 9개 이하라 항상 1.0이다. 보고는 하되 의미가 없다.

읽는 법:

- **성능을 올린 것은 피처 재설계 하나다**(폴드 +0.06). 부스팅·Extra Trees 계열 8가지는 0.814~0.821 범위에 모두 들어가고(Random Forest·MLP는 0.80, 선형 모델은 0.78), 튜닝은 +0.003, 혼합·시드 평균은 0에 가깝다.
- 피처를 더 넣어도(263개), 데이터를 9배로 늘려도 폴드 0.823에서 멈춘다. 같은 지점에서 여러 방법이 함께 멈추는 것은 정보의 한계이지 모델의 한계가 아니다(6절).
- 복제 패널은 같은 생성기에서 난수만 달리해 뽑은 독립 패널(학습 절단월까지만 생성)이다. 이득이 +0.005에 그쳐 **채택하지 않았다.**
- 4단계 선택 규칙은 한 번 바꿨다. 처음 규칙(폴드 동률 중 가장 작은 집합)은 30개를 골랐는데, 같은 폴드 점수에서 검증이 0.016 낮았다. 2019년 이전 폴드로는 동료 편차·정책 피처의 가치를 가릴 수 없어서다. 동률 후보는 검증으로 고르도록 바꿨고 두 규칙과 다섯 점수를 `feature-set.json`에 남겼다.
- 1단계의 Random Forest는 처음 설정(300그루, 깊이 제한 없음)이 실행 시간 제한에 걸려 100그루·깊이 18로 줄여 다시 돌린 값이다.

| 항목 | 값 |
|---|---|
| 버전 | `xgb-v2f-v3-calibrated-17items` |
| 순위 모델 | XGBoost `binary:logistic`, 800그루, 깊이 5, 학습률 0.048, min_child_weight 1.3, subsample 0.83, colsample 0.77, λ 0.33, γ 0.64 — 순위 점수는 로짓 마진 |

피처 v2(`ml/benchmark/features_v2.py`)가 새로 재는 것:

- **계절 위치** — 60개월 이력에서 12개월 이동평균을 뺀 잔차에 1차 조화를 맞추고(같은 품목의 후보국 경로를 묶은 중앙값 기준, 뚜렷이 다른 경로만 자기 계수), 예측 구간과 현재 구간의 계절 차이를 계산한다. 같은 달력 위치의 과거 연도 변화(seasonal naive)도 함께 쓴다.
- **주기 상태** — 계절을 뺀 계열의 3·6·12·48개월 기울기, 가속, 최근 36개월 최고·최저점 이후 개월 수와 그 사이 위치, 하위 20% 수준 대비 높이, 연속 상승·하락 개월.
- **현재 격차** — 라벨의 분모인 최근 3개월 평균이 자기 6·12·24·48개월 평균에서 얼마나 벗어났는지, 그리고 "계절 차이 − 격차"로 만든 기대 변화와 두 다리 중 약한 쪽의 임계값 여유(`ts_min_exp`).
- **동료 편차** — 같은 질의의 다른 후보국 중앙값 대비 편차.
- 모두 이용 가능월 ≤ 기준월인 행만 쓴다. 기준월 이후 공개된 행을 지워도 블록 전체가 비트 단위로 같다는 것을 테스트로 고정했다.

## 6. 0.85에 도달하지 못한 이유

패널은 `ml/build_db.py`가 만든다. 생성기를 그대로 재현하면(`benchmark/replay.py`, DB 1,574,370개 셀과 전부 일치) 데이터베이스에 없는 숨은 상태 — 계절·잡음·성장 에피소드·정책 반응 성분 — 를 얻는다. 그것을 모델에 알려 주고 같은 학습기로 채점했다(`ceiling.json`, 시험 분할 미사용).

| + 진행 중인 에피소드의 **미래 경로**(아직 오지 않은 정점 포함), 정확한 계절·수준 경로, 정책 반응 크기 | 0.8956 | 0.8943 |

- 라벨은 성장 에피소드가 좌우한다. 경로는 6~12개월 오르고 같은 기간 내려오며, 다음 에피소드는 직전 정점 14~42개월 뒤에 시작한다. 현재 구간 중심에서 예측 구간 중심까지는 전망 3개월에서도 6~8개월이라, 그 사이에 새 에피소드가 시작하거나 진행 중인 상승이 정점을 찍는다. 그 시점은 기준월의 이력에 없다.
- 둘째 행은 실제 모델이 가질 수 없는 정보다(상승의 시작을 잡음 없이 즉시 안다). 실제로는 월 잡음(로그 0.05)과 상승 기울기(월 0.02~0.10)가 비슷해서 상승을 확인하는 데 몇 달이 걸린다. 그런 낙관적 상한조차 검증 0.81이다.
- 0.85를 넘으려면 셋째 행의 정보, 곧 아직 오지 않은 정점의 날짜가 필요하다. 이것을 쓰면 누수다.
- 데이터를 늘려도 풀리지 않는다: 독립 복제 패널로 학습 행을 9배로 늘렸을 때 +0.005(3절).
- 시험 구간이 검증보다 개선폭이 작은 이유: 시험 구간에는 관측 앵커 구간(2020~2024, 실제 신고 경로를 따르는 구간)과 2022~2023년 정책 사건 3건(러시아 1, 중국 2)의 반응이 들어 있다. 학습 분할(≤2018)에는 앵커가 없고, 반응을 끝까지 본 사건은 러시아 2014년과 북한 2017년 것뿐이며 중국 대상 사건은 한 건도 없다. 최근 자료까지 다시 적합하면 0.7686까지 오른다(5절).

요약하면 **현재 데이터 구조에서 누수 없이 달성 가능한 수준은 폴드 0.82, 검증 0.76, 시험 0.75~0.77이고, 이론적으로 낙관적인 상한이 0.81~0.86이다.**

## 7. 더 올리려면 정해야 할 것

0.85는 모델이 아니라 문제 정의를 바꿔야 나온다. 임의로 바꾸지 않았고, 선택지만 적는다.

1. **지표를 바꾸면** 이미 0.85를 넘는 지표가 있다 — Hit Rate@5 0.95, ROC-AUC 검증 0.86. 다만 Hit Rate@5는 무작위도 0.87이라 변별력이 없고, ROC-AUC는 질의 간 비교(계절로 대부분 설명됨)를 재므로 "질의 안에서 누구를 먼저 볼 것인가"와 다른 질문이다. 권하지 않는다.
2. **라벨을 강도 등급으로 바꾸면**(증가 폭 기준) 모든 질의에 정답 순서가 생기지만 기존 수치와 비교할 수 없다.
3. **패널 생성기를 바꾸면**(에피소드에 선행 신호를 넣거나 잡음을 줄이면) 숫자는 오르지만 평가 대상을 바꾸는 것이다. 관측 근거 없이 하면 허위 성능이다.
4. **실측 선행 지표를 수집하는 것**은 실제 문제의 정보량을 늘리는 유일하게 정직한 경로지만, **이 생성 패널의 지표를 올리는 수단은 아니다.** 패널의 성장 에피소드는 생성기가 난수로 정한 시점에 시작하므로 어떤 외부 실측 계열도 그 시점과 관련이 없다. 실측 지표의 효과는 라벨도 실측인 평가 구간을 따로 만들어야 잴 수 있고, 그것은 평가 대상을 바꾸는 결정이다. (이 항목은 처음에 "수집하면 성능이 오른다"는 뜻으로 읽히게 적혀 있었다. 2026-10-05에 바로잡고 아래 점검을 추가했다.)

손실은 대상국에 정책 사건이 있은 뒤 몇 해에 몰려 있다. 정책 반응은 한 대상국의 모든 경로를 같은 달에 끌어올리되 경로마다 크기가 다르고, 그 상승분이 60개월 이력에 남아 "지금 성장 구간의 어디인가"를 읽는 피처를 흐린다.

- 추가한 피처(`FeatureBuilderV2(common=True)`, 35개): 대상국의 모든 경로(17개 품목 × 후보국)의 계절 제거 로그 수출 계열을 각자 중심화해 월별 중앙값을 공통 움직임으로 잡고, 경로별 반응 크기를 1 쪽으로 당기는 능형 회귀로 추정한 뒤, 그 몫을 뺀 계열로 수출 다리 피처를 다시 계산한다(`adj_*_out` 31개 + 반응 크기와 제거분의 최근 흐름 `fac_*_out` 4개). 기준월까지 공개된 자료만 쓰고, 생성기의 사건 날짜·반응 모양 상수는 쓰지 않는다.

### 실측 구간 점검 (`ml/benchmark/real_probe.py`, `real-data-probe.json`)

저장소에 있는 실측 월별 신고(`data/integration.sqlite`)로 라벨까지 실측인 작은 평가를 만들어, 공급국 측 신고가 선행 신호가 되는지 확인했다.

- 범위: 대상국 러시아, 후보국 6개(아르메니아·인도·카자흐스탄·키르기스스탄·튀르키예·우즈베키스탄), HS6 6개, 2019-04~2026-06. 후보국의 대중국 수입 신고, 대러시아 수출 신고, 그리고 **중국이 신고한 대후보국 수출**(공급국 측 신고).
- 라벨·피처: 벤치마크와 같은 라벨 규칙, 피처 v2의 다리별 피처. 평가는 2023·2024·2025년 워크포워드, 후보가 6개라 NDCG@3과 질의 안 양성·음성 쌍의 정순 비율로 잰다(두 부류가 다 있는 질의 171개).
- **시점은 가정이다**: 후보국 통계는 기준월 3개월 전까지, 중국 통계는 1개월 전까지 알려진다고 뒀다. 이 행들의 `available_month`는 일괄 수집 때의 Comtrade 최초 공개일이라 공표 달력으로 쓸 수 없다.

|---|---:|---:|---:|
| 후보국 자기 계열만 | 0.7426 | 0.7681 | — |

- 가진 실측 자료에서는 공급국 측 신고가 순위를 개선한다는 증거가 없다(차이가 표준오차 안). 피처를 통째로 더하면 학습 행이 2천 개 수준이라 과적합으로 오히려 나빠진다.
- 표본이 작아 0.01 수준의 효과는 가려낼 수 없다. "효과 없음"이 아니라 "이 자료로는 확인되지 않음"이다.
- 부수 결과: 실측 계열에서도 피처 v2만으로 양성·음성 쌍의 77%를 바르게 놓는다(무작위 50%). 생성 패널 밖에서 잰 첫 수치지만, 시점 가정과 작은 표본 위의 값이다.
- 더 나아가려면 실측 구간을 넓혀야 한다: 다른 대상국·품목의 월별 신고(UN Comtrade), 공표 달력이 있는 빈티지, 통계 밖의 선행 자료(선적·환적 기록 등). 첫 번째는 아래 "실측 벤치마크"로 진행했다.

### 실측 벤치마크 (`ml/benchmark/real_bench.py`, `real-benchmark.json`)

위 점검을 대상국 4개 · 품목 17개 · 앱의 후보국 9개 전체로 넓혔다. 생성 행은 하나도 쓰지 않는다.

- 자료: 후보국이 신고한 대상국행 수출(기존 `data/observed-exports.json`에 2019년과 확장 8품목을 추가 수집)과, 이번에 새로 수집한 후보국의 품목별 전 세계 수입 신고(`data/observed-imports.json`, 2019-01~2026-06, 15,625행). 수집기는 `scripts/collect_observed_exports.py --imports`.
- 실측 경로(두 다리 모두 18개월 이상): 153개 — 러시아 87, 이란 34, 중국 32, 북한 0. 월별 수입 신고가 있는 후보국은 아르메니아·중국·카자흐스탄·키르기스스탄·튀르키예·우즈베키스탄·베트남이다. 인도는 이 경로로 월별 수입이 조회되지 않았고 UAE는 2019년분만 있다.
- 라벨은 벤치마크 규칙 그대로, 피처는 v2의 다리별 피처 66개(동료 편차·v1·국가 피처 없음). 채점은 2023-01 이후 기준월, 전망 3·6·12개월, 8,577행(양성률 11.4%).
- **시점은 가정이다**: 후보국 통계가 기준월 3개월 전까지 알려진다고 뒀다.
- 질의당 후보 수가 적다(3,871개 질의 중 1개 1,465, 2개 1,203, 3개 529, 4개 이상 674). 그래서 주 척도는 질의 안 양성·음성 쌍의 정순 비율이고, 프로젝트 주평가지표(NDCG@5, 양성 있는 질의)는 후보 5개 이상인 155개 질의에서만 계산된다.

| 순위 방법 | 쌍 정순 비율 (683개 질의) | NDCG@3 (294) | NDCG@5 양성 질의 (155) |
|---|---:|---:|---:|
| 무작위 | 0.502 | 0.491 | 0.565 |
| 최근 3개월 증가율(약한 쪽 다리) 순 | 0.401 | 0.404 | 0.476 |
| 생성 패널로만 학습한 모델 (학습 ≤ 2018-12, 실측 미사용) | 0.581 | 0.570 | 0.630 |
| 실측으로 학습한 모델 (연 단위 워크포워드) | 0.598 | 0.617 | 0.680 |
| 실측 학습 + 패널 모델 점수 | 0.607 | 0.638 | 0.710 |

쌍 정순 비율의 차이와 표준오차: 패널 모델 − 무작위 +0.079 (0.023), 실측 모델 − 패널 모델 +0.017 (0.018), 결합 − 실측 모델 +0.009 (0.008).

대상국별 쌍 정순 비율(질의 수): 러시아 무작위 0.499 / 패널 0.560 / 실측 0.604 / 결합 0.603 (516), 이란 0.576 / 0.534 / 0.542 / 0.593 (59), 중국 0.477 / 0.708 / 0.597 / 0.630 (108).

읽는 법:

- **생성 패널에서 배운 것이 실측에 통한다.** 실측 행을 한 번도 보지 않은 모델이 무작위보다 0.08 높다(표준오차의 3배 이상). 패널이 관측 통계로 보정됐다는 주장을 순위 과제에서 처음 확인한 수치다.
- **최근 증가율 순위는 무작위보다 나쁘다.** 실측 월별 교역은 급등 뒤 되돌아가는 성질이 강해서, "최근에 함께 늘어난 경로"를 위로 올리는 v1식 직관은 이 라벨에서 거꾸로 작동한다.
- **실측으로 학습해도 0.60이다.** 실측 월별 신고는 잡음이 커서(로그 잔차 표준편차 0.3~1.5) 예측 가능한 부분이 작다. 실측 모델과 패널 모델의 차이, 결합의 이득은 표준오차 안이다.
- 이란은 질의가 59개뿐이라 어떤 차이도 판단할 수 없다. 북한은 실측 경로가 없다.
- 생성 패널의 0.75와 이 표의 숫자는 비교 대상이 아니다. 자료(생성/실측), 후보 수, 피처 범위가 모두 다르다.

**평가용 후보국을 넓힌 풀.** 후보 목록이 짧다는 약점을 줄이려고, 공개 보도에서 경유지로 거론되는 8개국(조지아·아제르바이잔·몽골·세르비아·홍콩·태국·말레이시아·타지키스탄)의 수출·수입 신고를 평가 전용으로 더 수집했다(`--wider`, `data/observed-wider.json`: 수출 8,117행, 수입 17,262행, 각 90개월). 앱의 후보국 목록은 바뀌지 않는다. 첫 수집은 공개 API의 일일 한도(HTTP 403)에서 멈췄고, 구독 키를 쓰는 엔드포인트로 나머지를 받았다. 타지키스탄은 월별 신고가 없고 몽골은 경로 기준(두 다리 18개월)에 못 미쳐, 실제로 더해진 나라는 6개다.

- 실측 경로 274개 — 러시아 134, 이란 48, 중국 92, 북한 0. 채점 18,150행(양성률 15.7%), 질의 4,476개 중 후보 5개 이상이 1,847개.

| 순위 방법 | 쌍 정순 비율 (1,814개 질의) | NDCG@3 (1,408) | NDCG@5 양성 질의 (1,107) |
|---|---:|---:|---:|
| 무작위 | 0.498 | 0.441 | 0.531 |
| 최근 3개월 증가율(약한 쪽 다리) 순 | 0.414 | 0.380 | 0.490 |
| 생성 패널로만 학습한 모델 | 0.569 | 0.490 | 0.585 |
| 실측으로 학습한 모델 (연 단위 워크포워드) | 0.597 | 0.522 | 0.596 |
| 실측 학습 + 패널 모델 점수 | 0.608 | 0.535 | 0.614 |

쌍 정순 비율의 차이와 표준오차: 패널 모델 − 무작위 +0.071 (0.011), 실측 모델 − 패널 모델 +0.027 (0.010), 결합 − 실측 모델 +0.012 (0.004).

대상국별 쌍 정순 비율(질의 수): 러시아 무작위 0.493 / 패널 0.583 / 실측 0.581 / 결합 0.601 (775), 이란 0.509 / 0.568 / 0.734 / 0.740 (199), 중국 0.501 / 0.557 / 0.579 / 0.584 (840).

- 표본이 2.7배가 되면서 앞 표에서 표준오차 안이던 차이가 갈렸다. 세 단계 모두 표준오차의 2.5배 이상이다: 패널 모델은 무작위보다, 실측 모델은 패널 모델보다, 결합은 실측 모델보다 높다.
- **패널 모델의 점수는 실측 모델에 없는 정보를 더한다.** 실측 행만으로는 배우기 어려운 규칙(계절 위치, 주기 상태)을 긴 생성 패널에서 배워 온다는 뜻이고, 생성 패널의 쓸모를 실측에서 확인한 결과다.
- 러시아 대상에서는 실측을 한 번도 보지 않은 패널 모델(0.583)이 실측 모델(0.581)과 같다.
- 후보 수가 늘어 무작위의 NDCG@5가 0.565 → 0.531로 내려갔다. 그 위에서 결합 모델은 0.614다. 생성 패널의 같은 지표(무작위 0.54, 모델 0.75)보다 무작위 대비 이득이 훨씬 작다: 실측 월별 교역에는 예측 가능한 부분이 적다.
- 새로 더한 6개국은 앱의 후보국이 아니므로 이 표는 "방법이 다른 나라에도 통하는가"에 대한 답이지 앱 화면의 순위 평가가 아니다.

## 11. 한계와 남은 일

- 생성 패널 안의 순위 성능이다. 실제 우회 적중률·지정 선행 탐지 성능은 검증하지 않았다.
- 피처 v2의 계절·주기 피처는 일반적인 시계열 기법이지만, 이 패널의 구조(12개월 정현 계절, 오르내리는 에피소드)에 잘 맞는다. 실측 자료에서 같은 이득이 난다는 근거는 없다.
- 검증 구간은 구성 선택에 쓰였다. 독립 추정은 시험 구간 하나이고, 시험 표본(양성 있는 질의 1,701개)의 표준오차는 약 0.006이다.
- 보조 헤드(금액 전망)는 개선되지 않았다. 필요하면 로그비 회귀를 부스팅으로 바꾸는 것이 다음 후보다(1라운드 E05의 회귀 접근이 검증에서 가장 높았다).
- 북한 대상(0.61)이 가장 약하다. 수출 신고 결측 18%가 현재 구간 평균을 흔든다.
- 서빙 지연: 대상국·기준월·전망 블록 하나(17품목 × 후보국 전체)를 만드는 데 약 0.4초로 기존 25특징 계산(0.16초)의 2.5배다. 분석 한 번은 블록 3개를 쓰고 결과는 캐시된다.
