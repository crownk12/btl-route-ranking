# ML Pipeline — 배포본 기준 (2026-10-05)

## 데이터와 구분

현재 `data/test.db`는 1990.01–2026.09의 **관측 자료로 보정한 생성 패널**이다. 대상국 4개, HS6 품목 17개, 경로 595개(러시아·이란·북한 각 9후보, 중국 8후보), 441개월, 최초·수정 2판본으로 총 524,790행이다. 패널 종료월은 `ml/build_db.py`의 `PANEL_END`(2026-09)로 고정한다. 난수열 길이가 패널 길이에 따라 달라져 종료월이 바뀌면 전 구간 값이 달라지므로, 언제 새로 설치해도 배포 모델이 학습한 패널과 같은 행이 만들어진다. 패널을 연장할 때는 `BTL_PANEL_END=YYYY-MM`으로 빌드하고 재학습·재배포를 함께 한다. 원본 교역 통계와 동일하지 않다. `ml/build_db.py`는 `data/panel-parameters.json`의 모수와 152개 앵커 경로를 사용하며, 추가 8품목은 별도 모수 추정이 없는 pooled fallback을 사용한다. 시연 완화 계수는 `metadata.demo_caps`에 기록돼 있다.

## 특징과 추론

배포 버전은 `xgb-v2f-v3-calibrated-17items`다(2026-10-05, 벤치마크 v14). 800개 XGBoost 분류 트리(`binary:logistic`, 순위 점수는 로짓 마진)와 64개 Extra Trees 보조 회귀 트리를 사용한다. 출력 세 열은 순위 마진, 미래 수입 로그비율, 미래 수출 로그비율이다. 이전 배포 `xgb-ranker-25f-v3-calibrated-17items`(25특징, XGBoost Ranker 300그루)는 `models/archive/`에 있다.

입력은 80개이며 `artifacts/model-benchmark-v14/feature-set.json`에 목록과 선별 근거가 있다.

기본 12개는 `backend/common.py::Panel.features`, 기존 확장 특징은 `ml/benchmark/features.py::FeatureBuilder`, 새 특징은 `ml/benchmark/features_v2.py::FeatureBuilderV2`가 만든다. 서버와 학습 행렬은 같은 함수 `FeatureBuilderV2.block`(대상국 × 기준월의 모든 품목·후보국·전망기간)을 쓴다. 60개월 이력에서 이용 가능월 ≤ 기준월인 행만 읽으며, 기준월 이후 공개된 행을 지워도 블록 값이 같다는 것을 `tests/test_benchmark.py`가 확인한다. 개별 국가명·HS6 문자열은 입력하지 않지만 HS 2자리 장은 `hs_chapter`로 사용한다. 서버는 모델 팩의 특징 목록을 보고 빌더를 고르므로 보존된 25특징 팩도 그대로 서빙된다.

`ml/runtime_model.py`는 `models/runtime-model.json`이 있으면 NumPy만으로 읽는다. 없을 때 보존된 `models/model.joblib`을 사용한다. JSON은 `scripts/export_runtime_model.py`가 같은 학습 트리를 변환한다. 학습을 다시 하지 않으며 원본 모델을 덮어쓰지 않는다.

후보별 마진을 질의 안에서 지수화하고 Top-5 합을 100%로 정규화한다. 확보율 25% 미만 후보는 최하위 점수로 내린다. 이 값은 상대 우선순위이며 우회 확률·교역 비중이 아니다. 새 모델의 Top-5 비중은 이전보다 조금 더 1위에 쏠린다(1위 비중 중앙값 31% → 37%, 272개 질의 표본). 군수 경로 모드가 활성화되면 기존 ML 순위 비중과 별도 군수 규칙 비중을 50:50으로 결합한다. 아래 모델 평가는 이 최종 혼합 순위의 별도 실증 성능이 아니다.

공개 사건 265건과 군수 네트워크는 별도 근거다. 순위 특징의 정책 사건은 `test.db.events` 8건이다. 새 근거 추가는 모델 재학습 또는 성능 향상을 뜻하지 않는다. 사례는 사건일과 문서 공표일 중 늦은 월부터 분석·하네스에 제공하며, 연표는 사건일 기준 회고 화면이다.

## 실제 평가와 목표

**주평가지표는 양성이 1건 이상인 질의의 NDCG@5이고 목표는 0.85 이상이다. 현재 미달성이다(시험 0.7472).** 다른 모델의 Hit Rate@5, 다른 품목 집합, 최종 운영 모델의 학습내 예측값을 달성 성능으로 사용하지 않는다.

**0.85에 도달하지 못한 이유.** 라벨은 성장 에피소드(6~12개월 상승, 같은 기간 하락, 다음 에피소드는 직전 정점 14~42개월 뒤)에 좌우되고, 에피소드의 시작과 정점 시점은 기준월의 이력에 없다. 생성기를 재현해(`ml/benchmark/replay.py`, DB와 전 셀 일치) 숨은 상태를 모델에 알려 준 상한 진단(`ceiling.json`, 내부 폴드 / 검증): 실제 모델 0.821 / 0.750, 진행 중인 에피소드의 현재 상태를 정확히 알 때 0.856 / 0.810, 아직 오지 않은 정점까지 알 때 0.896 / 0.894. 0.85는 기준월에 알 수 없는 정보가 있어야 넘는다. 부스팅·Extra Trees 계열 8종·특징 263개·학습 행 9배(독립 복제 패널)는 모두 폴드 0.82 근처에서 멈췄다. 실험 전체와 근거는 `artifacts/model-benchmark-v14/FINAL_REPORT.md`에 있다.

라벨은 기준월 b의 이용 가능한 최근 3개월 평균 대비 미래 b+h … b+h+2월 평균이 수입 15%·수출 20%를 모두 초과하는 경우다. 라벨 성숙월은 b+h+7이다. 학습 성숙월 ≤2018.12, 검증 기준월 ≥2019.01·성숙월 ≤2021.12, 시험 기준월 ≥2022.01·성숙월 ≤2026.09로 나눈다. 질의는 target×HS6×기준월×h다. 검증·시험 기준월은 4개월 간격, 학습 기준월은 2개월 간격이다. h=3·6·12·24·60·75를 학습하지만 검증·시험에 60·75개월 표본은 없다. 75개월 UI 전망을 검증된 장기 예측이라고 말하지 않는다.

특징·모델·하이퍼파라미터는 학습 구간 안의 3개 롤링 폴드(절단 2009-12 / 2012-12 / 2015-12)로 고르고, 폴드에서 동률인 후보만 검증으로 골랐다. 평가용 학습은 445,990행이다. 채택 후 운영 모델은 성숙한 전체 610,067행으로 다시 학습되므로 그 모델을 시험행에 적용한 값을 독립 시험 성능으로 보고하지 않는다. 보조 헤드(금액 전망 로그비)의 시험 MAE는 0.3585 → 0.3609로 나아지지 않았다.

홀드아웃(검증 구간): 대상국 하나, 품목 하나, 후보국 하나를 학습에서 뺀 모델의 손실은 평균 0.006, 0.011, 0.007이다.

**수출 단기 급증 점수 (별도 과제).** 동반 증가 과제와 따로, 후보국의 대상국행 수출만 보는 단기 과제를 별도 모델로 둔다(`ml/benchmark/export_track.py`, `models/export-model.joblib`, `models/export-metrics.json`). 라벨은 b+h … b+h+2월 평균 수출이 최근 3개월 평균보다 20% 넘게 늘어나는 경우이고 h는 1과 3이다. 모델은 `xgb-export-surge-v2-17items`(XGBoost 분류기 600그루, 같은 80개 입력 + 공통 움직임을 걷어낸 수출 다리 35개), 화면에는 기준월 다음 3개월 구간(h = 1)의 후보국 간 순위가 "단기 수출 n위" 칩으로 나오며 동반 증가 비중과 섞지 않는다.

|---|---:|---:|---:|---:|

목표 0.85는 미리 정한 프로토콜(학습 분할로만 적합)로는 **미달(0.8387)**이고, 매년 재적합하는 워크포워드로는 0.8750이다. 판정은 앞의 값으로 기록한다.

**v2에서 바뀐 것 (공통 움직임 제거).** v1은 내부 폴드와 검증에서 대상국에 정책 사건이 있은 뒤 몇 해 동안만 점수를 잃었다(검증: 러시아 0.83, 북한 0.79, 사건이 없던 중국 0.93). 정책 반응은 한 대상국의 모든 경로를 같은 달에 끌어올리되 경로마다 크기가 다르고, 그 상승분이 60개월 이력에 남아 수준·범위·기울기 피처가 성장 구간으로 잘못 읽는다. `FeatureBuilderV2(common=True)`는 기준월까지의 자료만으로 (1) 대상국의 모든 경로(17개 품목 × 후보국)의 계절 제거 로그 계열을 각자 중심화해 월별 중앙값을 공통 움직임으로 잡고, (2) 경로별 반응 크기를 1 쪽으로 당기는 능형 회귀로 추정하고, (3) 그 몫을 뺀 수출 계열로 다리 피처를 다시 계산한다(`adj_*_out` 31개, 반응 크기와 제거분의 최근 흐름 `fac_*_out` 4개). 생성기의 사건 날짜나 반응 모양 상수는 쓰지 않는다. 내부 폴드는 v1과 동률(0.9287 → 0.9296), 검증은 0.8645 → 0.8724(3개 시드 평균 +0.0072, 질의 단위 짝지은 부트스트랩 95% 구간 +0.0022 ~ +0.0124)이고, 기존 규칙(폴드 동률이면 검증)이 v2를 골랐다. 시험 구간은 v1 때 한 번 읽었으므로 v2 평가는 **두 번째 열람**이며 `export-evaluation.json`의 `test_readings`와 `previous_version`에 그렇게 적혀 있다. 실제 정책 항을 정확히 걷어내는 경우의 검증 이득은 약 +0.026이라 이 방향으로 남은 여지는 작다.

이 점수의 해석은 v1과 같다. 무작위가 0.63으로 높아서(후보의 37%가 양성) 무작위 대비 이득은 동반 증가 과제와 같은 크기(+0.20)다: 이 점수가 높은 것은 과제가 더 예측 가능한 몫과 과제가 쉬운 몫을 합친 결과다. 수입 다리가 라벨에 없으므로 경유 특징은 이 점수에 담기지 않는다.

**실측 벤치마크.** 위 수치는 생성 패널 안의 값이다. 실측 월별 신고만으로 같은 라벨과 순위 과제를 만든 별도 평가(`ml/benchmark/real_bench.py`, `artifacts/model-benchmark-v14/real-benchmark.json`)가 있다. 2023년 이후 기준월, 질의 안 양성·음성 쌍의 정순 비율 기준이다.

| 풀 | 실측 경로 | 무작위 | 최근 증가율 순 | 패널로만 학습 | 실측으로 학습 | 결합 |
|---|---:|---:|---:|---:|---:|---:|
| 앱의 후보국 9개 | 153 (러시아 87, 이란 34, 중국 32) | 0.502 | 0.401 | 0.581 | 0.598 | 0.607 |
| 평가용 8개국 추가 | 274 (러시아 134, 이란 48, 중국 92) | 0.498 | 0.414 | 0.569 | 0.597 | 0.608 |

넓힌 풀에서 차이의 표준오차는 0.004~0.011이고 세 단계(패널 모델 > 무작위, 실측 모델 > 패널 모델, 결합 > 실측 모델)가 모두 그 2.5배 이상이다. 생성 패널에서 배운 순위 규칙이 실측에도 통하고 실측 모델에 없는 정보를 더하지만, 실측 교역의 예측 가능한 부분은 작다. 공표 시점은 가정(기준월 3개월 전까지 알려짐)이고 북한 대상은 실측 경로가 없다. 이 값은 배포 모델의 성능이 아니다: 배포 모델의 80개 입력 중 다리별 66개만 쓴 별도 적합이며, 추가 8개국은 앱의 후보국이 아니다.


벤치마크 v14 재현(학습 환경 `.venv-bench`: `pip install -r requirements-benchmark.txt`, `ml/`에서 실행): `python -m benchmark.lab build` → `python -m benchmark.final all` → 프로젝트 루트에서 데모 환경으로 `python scripts/deploy_ranker.py`. 실험 라운드(`benchmark.exp_round1` … `exp_round6`)와 상한 진단(`benchmark.ceiling`)의 실행법은 각 모듈 머리말에 있다.

시연 실행은 `python launch.py`다. 점검만을 위해 `ml/build_db.py`, `ml/train.py`, `scripts/deploy_ranker.py`를 실행하지 않는다. 이들은 패널 또는 모델을 변경한다. 재학습 시 별도 학습 환경·SQLite 백업·분할 보존이 필요하며, 절차는 `ml/benchmark/final.py`와 `scripts/deploy_ranker.py`에 있다(v12/v13 절차는 `ml/benchmark/export.py`, `scripts/export_panel_candidate.py`). 원본 9품목 모델과 이전 17품목 25특징 모델은 `models/archive/`에 보존돼 있다. 되돌리려면 해당 폴더의 `model.joblib`·`metrics.json`을 `models/`로 복사하고 서버를 재시작한다.

평가는 생성 패널의 미래 교역 증가 순위에 한정된다. 실제 우회 적중률·공식 제재 선행 탐지 성능은 미검증이다. 원본 빈티지와 충분한 실측이 쌓이기 전에는 이 한계를 목표 달성 주장으로 대체할 수 없다. 실험·선택·시험 평가·상한 진단의 전체 기록은 `artifacts/model-benchmark-v14/FINAL_REPORT.md`에 있다.
